# 周线资金压力监控器 V1

参考视频的板块 → 细分行业 → 个股周线监控流程，使用透明的20日CMF压力算法。设计依据见 [DESIGN_V1.md](DESIGN_V1.md)。

## 启动与更新

页面侧栏提供两个独立按钮：

- **下载最新行情并计算**：从 Yahoo 下载当前股票池近3年行情及市值，显示批次/重试进度。最近已收盘NYSE交易日的新行情覆盖率达到95%且通过计算校验后，允许部分更新；低于95%、日期倒退或校验失败时保留整份旧数据。成功后自动选择最新可计算周。
- 失败股票仅保留原有历史（新成员可能没有历史），不填充新日期、不冒充新行情，仍保留在成员分母中。页面显示失败代码、原因和已有行情截止日期。该95%下载门槛与各板块95%的正式排名门槛分别检查；行情有效不代表20日压力窗口有效。
- **重新校验本地数据**：不联网下载，仅重新读取已有文件并计算，保留所选观察周。

侧栏显示行情截止日期和上次下载时间（北京时间）。下载完成不保证出现新的一周，仍取决于行情日期和完整交易周。此功能是手动更新，不是定时下载。

双击 `open_monitor.cmd` 即可启动并打开页面，已运行时不会重复启动。
Windows 登录自启动入口为用户“启动”文件夹中的 `Flyfish Market Monitor.lnk`；删除该快捷方式即可取消自启动。
启动脚本 `start_monitor.ps1` 只启动本地服务，不自动下载行情。启动日志为 `monitor-startup.out.log` 和 `monitor-startup.err.log`。

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\update_data.py --universe sp500 --years 3 --skip-market-cap
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8501 --server.headless true
```

浏览器打开 http://localhost:8501/ 。已有真实行情时无需每次重新下载。命令行更新后点击“重新校验本地数据”；后台进程停止后需重新启动。没有真实输入时可用下载按钮获取行情，不自动使用演示数据。

## 指标

只补充当前市值（无需重新下载行情）：

```powershell
.\.venv\Scripts\python.exe scripts\update_data.py --market-cap-only
```

完成后点击“重新校验本地数据”。市值请求使用fast_info的marketCap字段，失败时尝试info并有限重试；仍失败则保留原值与原获取时间。页面标注当前市值、获取时间和缓存状态。

- Self = 100 × 最近20个连续NYSE交易日的Σ(M×成交量)/Σ成交量。
- M = (2×收盘价−最高价−最低价)/(最高价−最低价)，高低价相同时为0。
- Rel = Self − 同周有效股票Self中位数。
- 板块、细分行业直接对股票等权平均，市值和涨跌幅不参与评分。
- Self与Rel排名一致，零点含义不同；Rel改善也可能来自市场基准下降。
- 广度分为Self正向占比与Rel正向占比，两者分开展示。
- 分数是量价压力代理，不是美元资金流或机构交易记录，也不保证与CoreEdge私有算法一致。

## 数据与质量

使用Yahoo Finance日行情及拆股事件、NYSE日历和当前股票池分类。仅显示已结束的完整周；缺失、重复、无效OHLCV、全零成交量及跨拆股窗口均排除。拆股窗口暂不尝试未经核验的成交量转换。异常量能超过此前20日成交量中位数10倍时标记，不截尾。

覆盖率≥95%且至少3只有效成员的组进入正式排名，其余显示覆盖及临时结果；少于3只不展示组分数。所有组保留有效/应覆盖数。历史按当前成员回溯。现阶段为标普500股票池，不是全美股，也不是ETF持仓或申购赎回。主题扩展属于下一阶段。

零市值覆盖时显示缺失值，评分仍为等权。数据源可能修订历史，需留存版本；个人研究使用不代表拥有商业再分发授权。

## 快照与审计

每次输入、代码或完整周改变会产生独立run_id。data/snapshots/<run_id>/保存股票、板块、行业、成员、原始输入、算法及清单。页面支持导出所选周股票快照；个股下方显示20日原始计算表。

旧rotation/model.py和backtest.py仅保留作旧版研究记录，新应用不调用旧收益混合评分或盈利回测。
