1. [完整研究报告](<研究报告.md>)：为什么这样设计、三层边界、反馈机制、长短周期协同与评价方法。

4. [研究来源与证据边界](<研究来源与证据边界.md>)：外部研究与本地材料，区分研究依据、设计建议和仍待验证的效果。

本次交付为设计研究与落地规格，未搬迁公司档案、修改现行估值/仓位规则、运行历史模拟或部署自动任务。目录建议和模板均为拟议设计，不是当前已运行的系统。

## 最小启动方式

先在 TCOM 运行一个完整前瞻循环：登记 3–5 条长期关键判断与少量到期可结算预测；选一类有明确规则的短期交易设想；冻结输入与规则；等新证据或到期后分别结算；记录哪条研究方法需要修正。旧材料用于重建历史，不把事后补录伪装成事前预测。

随后扩展至一个对照公司，再按有意义的研究覆盖度扩展到整个公司库。第一阶段不以收益提升证明成功，而以“关键判断有来源、旧版可复现、结果按原标准结算、长短仓位不混账”验收。
