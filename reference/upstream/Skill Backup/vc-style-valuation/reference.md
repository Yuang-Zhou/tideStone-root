## A. 相变信号表（Step 3 用）—— 判断"生意会不会变性质"

有证据才算成立。任一成立且证据扎实 → 走完整承销；基本不成立 → 温和重估（上限 2–3x）。

| 信号 | 含义 | 典型行业 |
| :--- | :--- | :--- |
| 第二曲线 | 新业务增速远超主业、占比还小（<15%）、甚至还在亏 | 通用 |
| 经营杠杆拐点 | 毛利已高/转正，但因增长性投入经营仍亏；投入停涨则利润跳升 | SaaS/互联网/云 |
| 变现方式改变 | 一次性卖货 → 重复性收费（订阅/服务/抽成/年金） | SaaS/航天售后 |
| 单位价值量/份额结构性跃升 | 单机或单客户价值量、或市占率台阶式上升 | 半导体/硬件 |
| 商品→独家供货（定价权） | 从可替代变成 sole-source | 半导体/零部件 |
| 装机量→售后年金 | 卖设备（低毛利）→ 装机基数产生几十年高毛利服务 | 航天/工业 |
| 网络效应/转换成本上台阶 | 单客户价值随规模非线性上升，或客户被锁定 | 互联网/平台 |
| TAM 被重新定义/重新归类 | 跨进大得多的相邻市场，或被市场改归类 | 通用 |

## B. 承销原型表（Step 4B 用）—— 选原型，填四格

**四格（通用）：**
1. 现在是什么在**压制**这杆矛的当前读数？（增长性投入费用化 / 产能折旧超前 / 学习曲线爬产 / 周期低谷）
2. 可复制的"**单元**"是什么？单元成熟经济好不好、复制它是"缺钱/缺时间"（可承销）还是"没搞定"（不可承销）？
3. 成熟**参照**去哪抄？（一个已跑到成熟的同类的利润率/take rate/毛利；规模上限用物理事实）
4. **反推疯不疯**？要十倍这杆矛得到什么水平，对应市占率/渗透率/单位价值量是否 sane（相对已存在的 TAM 和有人达到过的利润率）。

| 原型 | 压制当前读数的 | 可复制单元 | 成熟参照 | 重新定价扳机 |
| :--- | :--- | :--- | :--- | :--- |
| SaaS/软件 | S&M 前置费用化 | 客户 cohort（NRR、回本期、LTV/CAC） | 成熟 SaaS 的 FCF 利润率 30–40% | 亏损换增长 → 高留存复利机器，市场从 PS 改看可持续 FCF |
| 半导体 | 周期低谷 + 爬产 | 一个 design-win/socket（单机价值量×机型数） | 穿越周期的**中周期**净利率 | 单机价值量/份额跃升，或商品→独家供货 → 周期倍数升为成长倍数 |
| 航空航天/国防 | 学习曲线 + 研发前置 | 一个型号/项目（在手订单给可见性） | 量产成熟毛利 + 售后服务毛利 | 承包商 → 装机吃几十年高毛利售后年金 |
| 云/基础设施 | 数据中心 capex/折旧超前 | 一个 region 的利用率爬坡 | 成熟云稳态经营利润率 ~30%+ | capex 炉子 → 有经营杠杆的公用事业 |
| 互联网/平台 | 补贴+获客压平台利润 | 一个市场/地区或 cohort | 成熟平台 take rate 与经营利润率 | 网络效应起、CAC 降、take rate 升、叠新变现层 → 从 GMV 倍数改看盈利能力 |

> **放弃出口（合法输出）：** 链条太长、要赌的变量 >2 个、或找不到可抄的成熟参照 → 输出"当前不可承销，列入观察名单"，不硬憋数字。

## C. "估值之矛"随阶段迁移（Step 4A 用）

不要默认用利润。判断退出**那个阶段**市场用哪杆矛：

| 公司阶段 / 类型 | 退出时最可能的估值之矛 | 对应倍数 |
| :--- | :--- | :--- |
| 高增长未盈利（有意压制利润换增长） | 收入 / ARR / GMV / 毛利 | P/S、EV/ARR、EV/GP |
| 增长放缓、开始释放利润 | FCF / EBITDA | P/FCF、EV/EBITDA |
| 成熟 / 周期股 | 利润 / FCF（周期股用中周期还原后利润） | P/E、P/FCF |

"稳态利润"只是矛=利润时的特例。矛在收入轴上时，就在收入轴上承销十倍，不必算到利润。

## D. 十倍拆解示例（Step 1.4 / 4E 用）

3 年 10 倍 ≈ 股价年化 +115%。

```
目标 MOIC(3年) ≈ 10x = 矛的增长 × 倍数变化(含换矛) × (1/稀释)
```

| 矛的增长（3年） | 需要的倍数变化 | 现实含义 |
| :--- | :--- | :--- |
| 3x（约44%/年） | 3.3x | 强重新定价 |
| 5x（约71%/年） | 2.0x | 中等重新定价 |
| 10x（约115%/年） | 1.0x | 纯靠矛的极陡增长，倍数不变 |

> 判据：讲不清"矛为何涨这么多"+"倍数凭什么变"，就没有十倍结构。
