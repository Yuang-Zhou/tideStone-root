# 进阶功能参考手册

## 一、SOTP 分部估值（业务异质性强的公司）

### 适用场景

- 公司有多个差异化业务板块（不同商业模式、不同WACC）
- 正常单一WACC反推会严重扭曲其中某个板块
- 典型案例：SpaceX（Starlink+Falcon+xAI）、Alphabet（搜索+Cloud+YouTube+Other Bets）

### 操作步骤

**Step 1：识别各业务板块**

| 板块 | 商业模式 | 适用估值方法 |
|------|----------|-------------|
| 有正FCF业务 | 订阅/SaaS/成熟业务 | 反推DCF（用各板块WACC） |
| 无FCF烧钱业务 | 早期AI/R&D | 最近私募估值锚 或 可比公司倍数 |
| 期权性业务 | 未来可能存在的市场 | 实物期权定性描述（DCF算不出来）|

**Step 2：各板块单独估值**

```
有FCF板块：
  各板块独立确定WACC（行业β不同）
  各板块独立反推隐含CAGR

无FCF板块：
  参考最近一轮私募估值
  或用可比公司 EV/Revenue、EV/GMV 等倍数
```

**Step 3：汇总 vs 总EV**

```
各板块价值之和 = 可估值业务价值
残差 = 总EV - 各板块价值之和
残差比例 = 残差 / 总EV × 100%
```

**解读残差：**
- 残差 < 20%：估值主要由可见业务支撑，较为稳健
- 残差 20-40%：市场对未来业务给了一定溢价，需关注兑现节奏
- 残差 > 50%：估值有相当部分来自"未来期权"，标准DCF无法定价

**Step 4：输出 SOTP 汇总表**

| 板块 | 估值方法 | 估值（B） | 占比 |
|------|----------|-----------|------|
| 板块A | 反推DCF | $XXX | XX% |
| 板块B | 私募估值锚 | $XXX | XX% |
| 可估值合计 | | $XXX | XX% |
| **残差（未来期权）** | | **$XXX** | **XX%** |
| **总EV** | | **$XXX** | **100%** |

## 二、同类公司隐含预期对比（Peer Comparison）

### 适用场景

- 同行业两家（或多家）公司，看市场对谁更"乐观"
- 理解相对定价差异背后的产业逻辑
- 典型案例：铠侠 vs SK海力士（同为AI受益memory股，定价天差地别）

### 操作步骤

**Step 1：统一口径建对比表**

| 维度 | 公司A | 公司B |
|------|-------|-------|
| 主营业务差异 | | |
| FY最新 FCF | | |
| 市值 / EV | | |
| EV/FCF | | |
| WACC | | |
| 隐含10年CAGR（Exit 15x）| | |
| 隐含10年CAGR（GG法）| | |

**Step 2：解释定价差异**

从以下维度分析为什么市场给出不同的隐含CAGR：
- 产品属性：垄断性 vs 竞争性；直接受益AI vs 间接受益
- 周期性：结构性需求 vs 传统周期性
- 护城河：技术壁垒高度、客户切换成本
- 管理层质量：承诺兑现记录
- 资本结构：净现金 vs 有息负债

**Step 3：识别"定价异常"**

```
若两家公司基本面相似，但隐含CAGR差距 > 10pt：
  → 分析差距合理性
  → 若差距难以用基本面解释，可能存在相对定价机会
```

**Step 4：构建情景矩阵**

```
场景A：公司A的定价逻辑正确
  → 公司B当前隐含CAGR应对应什么估值？

场景B：公司B的定价逻辑正确  
  → 公司A应该如何重新定价？
```

## 三、产业链上下游一致性验证（Chain Comparison）

### 适用场景

- 分析AI产业链、半导体产业链等垂直链条
- 验证上下游的隐含预期是否自洽
- 发现哪个环节被相对低估/高估

### 操作步骤

**Step 1：独立反推各环节**

各环节完全独立反推，不用任何一端作为另一端的输入（避免循环论证）。

**Step 2：建立产业链隐含预期图**

| 环节 | 代表公司 | EV加权隐含CAGR（Exit 15x）|
|------|----------|--------------------------|
| 上游设备/EDA | ASML、AMAT等 | XX% |
| 中游芯片 | NVIDIA、AMD等 | XX% |
| 下游云厂AI业务 | Azure、GCP等 | XX% |
| 下游云厂整公司 | Microsoft、Google等 | XX% |

**Step 3：分析gap的合理性**

```
若上游隐含CAGR > 下游隐含CAGR（gap > 5pt）：
  可能解释1：上游被资金轮动拉高，存在透支
  可能解释2：下游整公司有大量非AI业务拖低整体
  可能解释3：市场认为上游比下游更稀缺

若上游隐含CAGR < 下游隐含CAGR（gap > 5pt）：
  可能解释：市场认为上游是纯代工/商品属性，利润被下游截留
```

**Step 4：上下游财务互验**

```
芯片公司Hyperscaler相关收入 / Hyperscaler总Capex = 芯片占Capex比例

若芯片端需求CAGR持续 > 云厂Capex CAGR：
  → 芯片占Capex比例需持续上升
  → 验证这是否合理（有天花板）
```

**Step 5：输出结构性结论**

- 哪个环节的定价最激进？
- 哪个环节存在相对保守的定价？
- 整条产业链的故事是否自洽？任何一环松动的连锁影响？

## 四、终态反推（Cross-check）

作为主流反推DCF的交叉验证，适用于：
- 公司当前FCF为负（无法做基年反推）
- 想验证"10年后需要做到多大规模"是否有历史先例

### 公式

```
EV₂₀₃₅ = EV_今天 × (1+WACC)¹⁰
所需2035年EBITDA = EV₂₀₃₅ / 退出倍数
所需2035年收入 = 所需EBITDA / 目标EBITDA margin
所需10年收入CAGR = (所需2035年收入 / 今天收入)^(1/10) - 1
```

然后与历史高增长公司对比，判断是否有先例。
