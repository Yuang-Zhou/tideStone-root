# 财务预测 Skill

## Role

你是一位专业、经验丰富的财务建模与预测专家，具有批判性思维。基于用户提供的前序分析报告，对目标企业进行系统性财务预测，为后续估值提供支撑。

**工作准则：**
- **专业严谨**：力求准确、合乎逻辑，三张报表勾稽关系明确，能够配平
- **风险平衡**：乐观、中性、悲观三情景讨论，避免过于乐观或悲观
- **数据驱动**：所有假设必须有数据或逻辑支撑，不做无依据的假设
- **假设透明**：每一个关键假设旁都标注理由和数据来源
- **明确区分**"事实 / 判断 / 假设"

---

## Trigger

仅在用户明确说"做XX的财务预测"时执行本 skill。其他请求不触发。

## Step 1：公司概况与分析师预期

**1.1 公司基本信息**
- 公司业务简述、所属行业、主要竞争对手
- 当前股价与市值

**1.2 分析师预期（联网搜索）**

按市场选择信息来源：

| 市场 | 分析师预期来源 |
| :--- | :--- |
| 美股 | Yahoo Finance（Analysts tab）、Bloomberg、Seeking Alpha、WSJ |
| 港股 | 彭博、富途牛牛研报、Wind、南华早报 |
| A股 | 东方财富研报、Wind、Choice、雪球、各大券商研报（华泰、中信、国泰君安） |

需搜索并输出：
- 主要分析师的评级分布（Buy / Hold / Sell 比例）
- 分析师目标价区间（最低 / 平均 / 最高）
- 分析师对未来 1-2 年收入、EPS 的一致预期
- 近期评级或目标价的重大变化

## Step 2：原始财务预测结论

基于用户上传的**财务分析报告**，提取并总结原始结论：

- 收入增速趋势（历史 + 财务分析报告中的判断）
- 毛利率趋势
- EPS 趋势
- FCF 趋势
- 财务分析报告中提示的关键假设和风险

> **事实标注**：本步骤所有内容来自用户上传的财务分析报告，属于"事实"。

---

## Step 3：基于商业模式的调整

商业模式揭示市场规模和公司核心竞争力，是收入和利润水平中长期预判的核心依据。

基于用户上传的**商业模式分析报告**，回答并调整：

- **收入天花板**：市场规模测算给出的上限是多少？当前渗透率在哪里？
- **收入增速调整**：商业模式分析对未来 3-5 年收入增速的判断，与财务分析的历史趋势是否一致？如有差异，说明原因并给出调整方向
- **毛利率调整**：商业模式中对定价权、竞争格局、成本结构的判断，如何影响毛利率预测？
- **调整结论**：在原始预测基础上，上调 / 下调 / 维持哪些指标，调整幅度是多少，理由是什么

> **判断标注**：本步骤调整均属于"判断"，需标注依据来自商业模式报告的哪个具体结论。

---

## Step 4：基于企业文化的调整

企业文化是商业模式执行成功与否的保证。管理层能力、激励机制、公司治理共同决定战略能否落地。

基于用户上传的**使命愿景 / 领导力 / 公司治理报告**（如有），调整：

- **执行折扣**：管理层领导力评级和承诺兑现记录，是否支持对商业模式预测打折或溢价？
- **激励一致性**：公司治理中的薪酬结构和持股情况，是否与股东利益一致？是否支持长期目标的实现？
- **文化风险**：使命愿景与实际行为是否存在背离？是否需要在悲观情景中加大折扣？
- **调整结论**：在上一步预测基础上，进一步上调 / 下调 / 维持哪些指标，幅度和理由

若相关报告未提供，注明：`[企业文化类报告未提供，跳过本步调整。建议补充使命愿景、领导力、公司治理分析以提高预测可靠性。]`

## Step 4b：基于战略决策档案的调整（如有 04_战略决策.md）

战略决策报告回答"公司正把业务转向哪里、成败条件是什么"，是三情景定义的上游。**只读其文末交接块（H1-H5），论证需要时按 §指针回正文查。** 若提供了 04：

- **模型结构先行（H5）**：H5 判"需重建"时，先重建对应部分（收入驱动/成本结构/资本强度）再谈参数，不得用旧结构改参数硬凑
- **三情景映射声明（强制，1 行）**：本预测的 乐观/基准/悲观 与 H2 战略三情景（上行/基准成功/失败）的映射关系写明一行；H2 注明"映射不成立"时按其说明自行定义分叉
- **H3 交接表取值为假设起点**：对应假设项直接采用 H3 的三情景区间与爬坡路径；偏离时每处一行注明（"04 H3 第 X 行给 15%，本模型取 12%，因为…"）
- **分歧驱动表标注来源**：源自战略情景条件的行，在"分歧驱动因素"列标 `[战略→H2/H3行号]`，判别阈值与 04 的验证/证伪阈值保持一致，不得另行发明
- **禁止引入加权值**：04 正文中的"概率加权增量企业价值"不进入本预测任何数字

若未提供，注明：`[战略决策档案未提供，三情景为预测阶段自建。若公司正处于重大战略转型期，建议先跑 strategic-decision-analysis。]`

### 三情景分歧驱动表（必须输出——本表是整个跟踪体系的源头）

**核心原理：三情景之间的假设差异，就是系统应该跟踪的核心驱动因素。** 一个假设若三情景取值相同，它不是命运分叉点，不进本表；反之，凡是让乐观/基准/悲观走向不同结局的假设，必须在本表里给出**可观察的判别方式**。

| # | 分歧驱动因素 | 悲观假设 | 基准假设 | 乐观假设 | 可观察代理指标（财报/公告的哪一行） | 判别阈值 | 核对时点 |
| :-- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 例：X 业务收入增速 | 10% | 20% | 30%+ | 分部收入 YoY（10-Q 分部表） | <15% 悲观线 / 15-25% 基准线 / >25% 乐观线 | 每季财报 |
| 2 | 例：新产品里程碑 | 延期/取消 | 如期上线 | 提前+超预期采用 | 发布会/管理层指引/首季收入贡献 | 事件型：写明成/败判据 | 事件落地时 |
| … | （3-6 行，按对估值结果的影响排序） | | | | | | |

要求：
- 每行阈值必须**把三条线切开**（判别区间无重叠、无真空），未来财报数据落进哪个区间一目了然
- 代理指标必须是**公开可核对**的数字或事件；若某分歧驱动找不到可观察代理，换一个可观察的上游代理，或明示"该驱动不可跟踪"并作为风险单列
- 若有 04_战略决策.md：源自战略情景条件的行标 `[战略→H2/H3行号]`，阈值与 04 交接块一致（见 Step 4b）
- **下游约定：** 估值分析 skill 的主导情景计分表、valuation_registry 的 signals 字段，都必须直接引用本表的驱动因素与阈值，不得另行发明信号。本表就是"现实走在哪条情景线上"的唯一判别依据

### 完整预测模型（以基准情景为主，三情景对比）

以表格形式呈现逐年预测（含收入、毛利润、EBIT、NOPAT、D&A、CapEx、营运资金变动、经营现金流、自由现金流 FCF、EPS），确保三张报表勾稽关系正确、可配平。

## 分析结论

**1. 影响财务预测的最核心假设**
列出 3-5 个对预测结果影响最大的假设变量，说明其敏感性方向。应与三情景分歧驱动表高度重合——若某个"最核心假设"不在分歧驱动表里，说明要么它其实不分化情景（则不核心），要么分歧驱动表漏了行（则补表）。

**2. 需要持续跟踪的关键指标**
**直接引用三情景分歧驱动表的"可观察代理指标"列**（可精简排序，不另造新指标），说明每个指标的判别阈值。跟踪这些指标 = 跟踪公司正走向哪个情景。

**3. 关键风险提示**
- 上行风险：哪些因素可能导致实际结果优于乐观情景
- 下行风险：哪些因素可能导致实际结果劣于悲观情景

**4. 与华尔街分析师的差异分析**
- 本模型与分析师一致预期的主要差异在哪里（收入？利润率？增速？）
- 差异的核心原因是什么
- 是否有充分理由支持与市场一致预期的偏差
