# 财务安全体检：还得起吗、资产有没有水分

第 1 步做。只用底稿和附注（10-K Item 8）里的数字，不读叙事。目的不是打分，是回答两个问题：**这家公司会不会出事**（偿债与流动性）、**账面资产是不是真的**（资产质量）。七问回答"怎么赚钱"，这里回答"会不会死、账是不是实的"。

各项指标算法按 `metrics.md`。参照阈值只是提示，不是判决——重资产、公用事业、金融的正常水平完全不同，写结论时要给自身历史或行业惯例做参照。

每一块的结论固定三段：**看到什么** → **说明什么** → **红旗/黄旗/无**。红黄旗的定义：**红旗** = 12 个月内可能出事或账面明显失真；**黄旗** = 趋势在恶化、需要下游跟踪；**无** = 正常。不许把正常波动写成旗。

## A. 偿债与流动性

### A1 债务规模与结构

**看**：有息负债（含租赁）绝对值与 5 年变化；净负债（有息负债 − 现金及短期投资）；净负债/EBITDA；有息负债/权益；租赁负债占有息负债比例。

**去附注补**（Item 8 债务附注、租赁附注）：到期分布（1 年内、1–3 年、3–5 年、5 年后）、固定 vs 浮动利率、币种、加权平均利率、契约条款（covenant）及最紧的一条离触发多远、循环信贷额度未提取部分、担保与或有负债。

**怎么看**：
- 净负债为负 → 净现金，A 块大半不适用，写明现金是否受限（海外、监管、抵押）
- 净负债/EBITDA 持续上升而 EBITDA 没涨 → 借钱撑现状
- 3 年内到期 >50% 且 FCF 覆盖不了 → 再融资依赖，利率环境一变就是风险
- 浮动利率占比高 + 利息覆盖薄 → 利率敏感
- 租赁负债占比高 → 表面负债轻实际固定支出重，问 5 的固定成本要把租金算进去

**参照**：净负债/EBITDA <1 轻，1–3 常见，>3 黄旗，>4 红旗（重资产/公用事业可放宽 1 倍）。

### A2 偿付能力

**看**：利息覆盖 = 营业利润/利息支出；现金利息覆盖 = 经营现金流/利息支出；FCF/有息负债（几年还清）；5 年是否有净还债年份（`capital_allocation.net_debt_repayment`）。

**怎么看**：
- 利息覆盖 <3 且在下降 → 黄旗；<1.5 → 红旗
- FCF/有息负债 <10%（还清要超过 10 年）且到期集中 → 黄旗
- 一直在净借入、分红回购却没停 → 拿借来的钱回馈股东，07 和治理模块要看

### A3 流动性

**看**：现金及短期投资 / 1 年内到期债务；流动比率、速动比率（底稿有 `current_assets`/`current_liabilities` 才算，否则去附注或填 n/a）；营运资金是否为负及原因（负营运资金对零售/订阅是常态，对制造是风险）；未提取信贷额度。

**怎么看**：
- 现金覆盖不了 1 年内到期债务，且经营现金流为负或波动大 → 红旗
- 流动比率骤降但公司预收款重 → 可能是正常，看问 3 的现金转换周期
- 现金主要在海外或受限 → 可用现金要打折

### A4 表外与或有

**只从附注取**：经营租赁承诺总额、采购承诺、担保、未决诉讼计提与未计提上限、保理/供应链金融（应付账款里藏的债）、VIE 或未并表实体。有就列，没有写"附注未披露重大项目"。

**A 块结论（≤4 行）**：一句"还得起/紧/危险" + 支撑数；最紧的约束是什么（到期、利率、契约、现金位置）；12 个月内最可能出问题的点；旗。

## B. 资产质量

### B1 商誉与无形资产

**看**：（商誉 + 无形资产）/ 总资产；商誉 / 权益；有形权益 = 权益 − 商誉 − 无形（为负要标）；5 年商誉变化 vs 并购支出；减值历史（`annual.impairment`）。

**去附注补**：商誉按报告单元的分布、最近一次减值测试的关键假设（折现率、增长率）、"公允价值超过账面价值的幅度"（headroom）——headroom <10% 是减值前兆。

**怎么看**：
- 商誉 + 无形 >40% 总资产 → 黄旗，说明资产大半是买来的溢价，含商誉 ROIC 是真实回报
- 有形权益为负 → 不一定是问题（回购多的公司常见），但要在 F2 标明，清算价值为零
- 并购年份多、从未减值 → 要么真买对了，要么减值测试太宽松，看 headroom

### B2 应收账款

**看**：应收 / 收入 5 年趋势；应收增速 vs 收入增速；应收天数（问 3 已算，这里看质量）。

**去附注补**：账龄分布、坏账准备 / 应收总额、当年核销额、前几大客户集中度（Item 8 集中度披露）、是否有保理（卖出应收换现金，会让应收天数"变好"）。

**怎么看**：
- 应收增速超收入增速 10 个百分点以上，连续两年 → 黄旗：要么在放宽账期换收入，要么客户付不出钱
- 坏账准备/应收在降而账龄在拉长 → 计提不足，利润被撑高
- 有保理 → 应收天数要按保理前口径重算，不然问 3 的议价地位判断是错的

### B3 存货

**看**：存货 / 收入 趋势；存货增速 vs 收入增速；存货天数（问 3 已算）。

**去附注补**：存货构成（原材料/在产品/产成品——产成品占比骤升是卖不动）、跌价准备 / 存货、当年计提与转回。

**怎么看**：
- 存货增速远超收入增速 + 产成品占比升 → 黄旗，下期要么降价要么减值
- 跌价准备比例在降而周转在变慢 → 计提不足

### B4 资本化与其他"软资产"

**看**：资本化研发/开发支出 占（费用化 + 资本化）总额比例及趋势；递延税资产 / 总资产；长期投资、其他非流动资产占总资产（大而不明的要查附注）；固定资产折旧年限有没有拉长（折旧/固定资产原值的比率在降）。

**怎么看**：
- 资本化比例在升 → 当期利润被抬高，问 7 已列为候选，这里给数
- 递延税资产大 → 依赖未来盈利才能实现，盈利转弱时会一次性冲掉
- 折旧率在降而资本开支没降 → 折旧年限被拉长或新资产寿命更长，附注查会计估计变更

**B 块结论（≤4 行）**：账面资产里有多少是"硬"的（现金、固定资产、存货）、多少是"软"的（商誉、无形、资本化、递延税）；最可能减值或需要重估的项目；对利润的潜在影响量级；旗。
