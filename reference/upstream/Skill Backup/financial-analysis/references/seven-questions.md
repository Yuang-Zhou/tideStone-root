# 七个问题：只看数字，推断这是什么生意

只准用底稿和附注里的数字。每个问题按"看到什么 → 说明什么 → 如果对，还应该看到什么"作答。答不出来就写"数字不够，判断不了"，不硬答。

各项指标怎么算，统一按 `metrics.md`。偿债、流动性、资产质量已在第 1 步（`health-check.md`）做过，这里直接引用结论，不重算。

---

## 问 1：这是什么形态的生意

**看**：毛利率水平与波动、固定资产/总资产、资本开支/收入、折旧摊销/收入、存货天数、应收天数、递延收入/收入、研发/收入、销售费用/收入。

**怎么看**（这是提示，不是查表）：

| 数字组合 | 通常指向 |
| :-- | :-- |
| 毛利 >65%，资本开支 <5% 收入，递延收入显著，研发 + 销售占收入 40%+ | 软件 / 订阅 / 品牌 |
| 毛利 15–30%，存货天数 30–90，应付长于应收，资本开支中等 | 零售 / 分销 / 制造装配 |
| 固定资产 >50% 总资产，折旧 >8% 收入，毛利随周期大幅摆动 | 重资产周期 |
| 无毛利概念、利息收入为主、总资产/权益 >8 | 金融——切换到 metrics.md 的金融替代指标 |
| 研发 >30% 收入、收入波动大、里程碑式确认 | 生物医药 / 早期科技 |
| 毛利 40–60%，销售费用极高，资本开支低 | 平台 / 广告 / 消费品牌 |

**结论要写清**：重/轻资产、成长/成熟/收缩（收入增速 + 再投资率）、现金流形态（稳定/周期/前置投入后置回收）。

---

## 问 2：钱从哪来、留下多少、被谁分走

**看**：五年的逐层扣减——收入 → 毛利 → 营业利润 → 净利润 → 经营现金流 → 自由现金流，每一层留下多少、五年怎么变。再看主线之外被分走的：利息、税、少数股东、股权激励（不花现金，但稀释股东）。

**怎么看**：
- 毛利到营业利润扣得多 → 靠费用驱动的生意，去看费用是固定的还是跟着收入动的（问 5）
- 营业利润到净利润扣得多 → 负债重或税负重，去附注查
- 净利润到经营现金流扣得多 → 利润压在应收账款和存货里，没变成钱（问 7 的候选）
- 经营现金流到自由现金流扣得多 → 光维持现状就要花大钱，账面利润不是真能分的钱
- 股权激励/经营现金流 >15% → 现金流数字高估了股东实际拿到的
- **TTM 经营现金流的增长要拆两块**：利润贡献了多少、营运资金时点（应付账款增加、存货减少）贡献了多少。后者是当期的钱，不能当成经营能力年化。拆法：Δ经营现金流 − Δ净利润 − Δ折旧 ≈ 营运资金贡献
- **预收类收入（会员费、订阅费、合同负债）不等于分部利润**。获客、服务、返利的成本都摊在 SG&A 里。可以说"预收占营业利润 X%"，不能说"预收业务贡献 X% 利润"

**结论要写清**：每收 1 块钱，股东最后能拿到几分；哪一层扣得最狠、是这家公司的命门。

## 问 3：它在压谁、被谁压

**看**：现金转换周期 = 存货天数 + 应收天数 − 应付天数；预收/递延收入占收入比；应付账款/营业成本；客户预付与供应商票据。

**怎么看**：
- 现金转换周期为负 → 上下游在给它垫钱，说话硬气，扩张不需要自己掏钱
- 现金转换周期为正且越来越长 → 要么话语权在减弱，要么在用赊账换销售（问 7 候选）
- 预收款/递延收入涨得比收入快 → 客户愿意提前付钱，需求有黏性
- 应收天数远长于行业惯例 → 客户强势，或收入确认激进

**结论要写清**：这家公司在产业链里是先收钱的一方还是先垫钱的一方；这个地位五年里是在变强还是变弱。

---

## 问 4：增长靠什么

**看**：
- 增量利润率 = Δ营业利润 / Δ收入（3 年滚动）vs 平均营业利润率
- 再投资率 = (资本开支 − 折旧 + Δ经营性营运资金 + 并购) / NOPAT
- ROIC（按 metrics.md 定义，含商誉和不含商誉各一个）
- 资本开支产出 = 3 年累计 Δ收入 / 同期累计资本开支
- 并购贡献：并表年份收入跳变 vs 内生增速

**怎么看**：
- 增量利润率 > 平均利润率 → 规模效应是真的，每多做一块生意比以前更赚
- 增量利润率 < 平均利润率 → 新增的生意不如老生意赚钱，规模效应是假的或已经用完
- 增长 ≈ 再投资率 × ROIC 能对上 → 增长是自己挣出来的，能持续；对不上 → 靠收购、借钱或行业周期
- 含商誉的 ROIC 远低于不含商誉的 → 收购买贵了
- ROE 高但 ROIC 低 → 高回报是借钱撑出来的

**结论要写清**：增长是靠回报高还是靠砸钱多；这样还能持续多久（还有多少地方可投 + 回报率在升还是在降）。

## 问 5：成本里哪些是固定的、哪些跟着收入动

**看**：营业成本、研发、销售、管理、折旧各自五年增速 vs 收入增速；收入下滑年份（若有）各成本线怎么动。

**怎么看**：
- 某项成本长期涨得比收入慢、收入下滑时也不降 → 固定成本，是利润放大的来源，也是行业不好时的风险
- 成本跟收入同步涨跌 → 变动成本，利润率稳，但也没有放大效应
- 收入放缓时研发或销售费用反而加速 → 要么在为下一轮增长投入，要么在花钱硬买增长（第 3 步对照时查）

**结论要写清**：收入每变 10%，营业利润大概变多少；对手打价格战，它扛不扛得住。

---

## 问 6：管理层把钱花在了哪

**看**：5 年累计 + 逐年趋势——资本开支、研发、并购、回购、分红、净还债、股权激励；各占同期经营现金流的比例。底稿 `capital_allocation` 已经算好，研发从利润表取。

**怎么看**：
- 研发和资本开支占比在升 → 公司认为自己还有好项目可投
- 回购和分红占比在升、再投资在降 → 公司认为没有好项目了，开始把钱还给股东
- 回购金额 ≈ 股权激励金额、股本没减少 → 回购只是在抵消员工持股的稀释，不是在回馈股东
- 并购占大头、含商誉的 ROIC 在降 → 靠买公司掩盖自身增长停滞
- 主要在还债 → 在修复资产负债表，前几年可能借得太多

**结论要写清**：一句话——从花钱的去向看，公司处在什么阶段、管理层真正相信的战略是什么。**只推断，不评价这样花钱对股东好不好**（那是治理模块的事）。

---

## 问 7：哪里对不上

本该一起涨或一起跌的数字，反着走了。常见的：

- 收入在涨，经营现金流在降
- 应收账款涨得明显比收入快
- 毛利率稳，存货周转却在变慢
- 净利润在涨，交的税没跟上
- 研发费用率在降，资本化的研发在升
- 说在回购，股本数却在增加
- 折旧年限拉长了，固定资产周转"变好"了
- 预收款在降，收入还在涨（在吃老本）
- 经营租赁很大，表内负债却很小
- 经营现金流增速远高于净利润增速，且当期应付账款大增（用账期撑现金流）

每条写：看到什么 → 具体数字 → 至少两种可能的解释 → 谁去查。**真没有就写"未发现"，不许把正常波动写成异常。**
