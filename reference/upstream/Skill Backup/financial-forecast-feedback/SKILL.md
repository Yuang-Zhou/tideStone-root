# financial-forecast-feedback — 预测偏差分诊

## 定位

财务预测是"财务分析 + 定性判断（企业文化/商业模式/战略）"合成的。每季财报出来，预测和实际的偏差要回流。回流分两级：

```
偏差小、在预测区间内  → 一级反馈：只调 06 的预测参数，不动上游判断
偏差连续大、方向反   → 二级反馈：上游判断错了，按 商业模式→战略→企业文化 的顺序重审
```

本 skill 只负责**算偏差、判级别、出判定单**。三条铁律：

1. **只读不写。** 不改 `06/07`，不改 `valuation_registry.json`，不建 `_pending`，不派任何 sub-skill。判定单是研究记录，写到 `_deviation/`。
2. **只认档案里登记过的信号。** 比对对象是 06 的"三情景分歧驱动表"和"关键假设汇总表"，不临时发明新指标。
3. **实际值只认一手来源。** 用 `fetch_edgar_financials.py` 拉 SEC 申报数据；拉不到的项写"无数据"，不猜、不用第三方站点补。

与 research-event-update 的关系：**并存，互不调用，互不改动。** 那个 skill 管事件影响评估和定向刷新；本 skill 只管季报数字对预测的偏差。用户看完判定单要刷新，自己决定走哪条路。

## 触发条件

用户明确说：
- "做 {TICKER} 的预测偏差分诊"
- "{TICKER} 财报出了，对一下预测"
- "跑 {TICKER} 的偏差分诊 / 偏差复盘"

仅手动触发。不归本 skill：事件影响评估（→ research-event-update）、重做预测（→ financial-forecast）、建档（→ company-dossier-build）。

## 系统依赖

所有 bash 命令在 **Projects 根目录**执行。

| 路径 | 用途 |
|---|---|
| `_system/companies.json` | 查 ticker 对应的公司目录 |
| `{公司目录}/研究档案/06_财务预测.md` | 读三份东西：关键假设汇总表、三情景分歧驱动表、完整预测模型（当年那一列） |

| `{公司目录}/{WIKI} Wiki/raw/财务数据/EDGAR/` | 脚本产出落点：`financials.json`、`quarterly.csv`、`annual.csv` |
| `{公司目录}/研究档案/_deviation/` | 本 skill 的判定单累积处（不存在则创建） |

## 执行流程

### Step 0 — 前置检查（必须先做）

1. 用 `companies.json` 定位公司目录。找不到 → 停，提示先入库。
2. 确认 `06_财务预测.md` 存在且含"三情景分歧驱动表"。没有这张表 → 停，提示"该预测是旧格式，先重跑 financial-forecast 再分诊"。不要自己从假设表补一张。
3. 读 `_meta.json` 的 source_period，记下预测基于哪一期。
4. 读 `_deviation/` 下已有判定单，取最近两份。这是扳机 T1"连续两季"的依据。没有历史 → T1 本次不能触发，判定单里写明。
5. 读 07 §4.8 和 registry，记下**主导情景**和**置信度**。没有判定（dominant 为空）→ 仍可算偏差，但 T2/T3 无法核，判定单里写明"无主导情景，本次只出偏差表"。

### Step 1 — 拉实际值

```
python _system/scripts/fetch_edgar_financials.py {TICKER} --out "{公司目录}/{WIKI} Wiki/raw/财务数据/EDGAR/"
```

- 脚本会打印"未命中指标"清单，原样抄进判定单附录。未命中 ≠ 0。
- 确定**新进来的期数**：EDGAR 里 filed 晚于 source_period 的季度。一期都没有 → 停，告诉用户"预测已覆盖最新财报，没有新数据可对"。
- 金融股、外币 ADR 脚本不适用（见脚本边界）。这两类直接停，告诉用户本 skill 暂不支持。

### Step 2 — 逐行对分歧驱动表

对 06 分歧驱动表的每一行：

| 列 | 怎么填 |
|---|---|
| 驱动因素 | 原样抄 06 |
| 代理指标 | 原样抄 06 的"可观察代理指标"列 |
| 实际值 | 从 `quarterly.csv` 取。代理指标是分部数据或附注项目时 XBRL 主表没有，写"无数据（附注项）"，不凑 |
| 落区 | 按 06 的判别阈值判：悲观线 / 基准线 / 乐观线 |
| 与主导情景一致？ | 落区 = 主导情景 → 一致；相邻 → 偏一档；跨两档 → 偏两档 |

**口径对齐（必须做）。** 06 的假设是年度值，财报是单季值，不能直接比。先给每一行定类型，再按类型换口径：

| 指标类型 | 例子 | 怎么对 | 判定单里标什么 |
|---|---|---|---|
| A 增速 | 收入增速、分部收入增速 | 单季同比（今年 Q2 对去年 Q2）直接对年度增速假设。同比已抵掉季节性 | "同比口径" |
| B 比率 | 毛利率、营业利润率、资本支出占收入比 | 用 TTM（最近四个季度加总）算比率，对年度假设。单季比率只作参考，不判落区 | "TTM 口径" |
| C 绝对额 | 收入、FCF、资本支出、EPS | 把年度预测按**季节性比例**拆成季度再比（拆法见下） | "季节性拆分，Qn 占比 x%" |
| D 事件型 | 新产品上线、合同签署、里程碑 | 不看财报数字，只按 06 写的判据核事实。没证据写"本次未核" | "事件判据" |

**绝对额的季节性拆分：**
1. 从 `quarterly.csv` 取该指标过去三个完整财年的各季值，算每季占全年的平均比例。
2. 单季对比：Qn 预测值 = 年度预测 × Qn 平均占比，三情景各拆一个。
3. 过了两季以上，改用 YTD（年初到本季累计）对比：YTD 预测值 = 年度预测 × 前 n 季占比之和。样本大，更稳。**两种都算时以 YTD 为准。**
4. 历史不足三年的，用能拿到的年份，并标注"季节性样本不足 n 年"。
5. 拆分用的比例全部列进判定单附录，方便复核。

**季节性失效的情况**，这行的落区只作参考、不计入扳机，并在表里标"季节性可能失效"：
- 过去一年内有并购/剥离，改变了收入结构
- 新产品/新业务上量，收入节奏和历史不同
- 公司自己在财报里说本季有一次性项目（提前确认、递延）

**指引作为旁证。** 管理层给了季度或全年指引的，把指引相对 06 基准假设的方向单独写一行。指引含管理层对下半年的看法，方向信号常比单季实际值强。但指引只作旁证，不替代实际值、不单独触发扳机。

### Step 3 — 对关键假设汇总表

对收入增速、毛利率、营业利润率、资本支出占比这四项（其他项有数据就加）：

| 假设项 | 悲观 | 基准 | 乐观 | 实际（口径） | 落区 | 偏离主导情景值 |
|---|---|---|---|---|---|---|

"偏离"= 实际 − 主导情景假设值，带正负号。这张表是看**幅度**，Step 2 那张是看**区间**。

### Step 4 — 核三条扳机

任一条命中 → 二级。三条都不命中 → 一级。

| 扳机 | 条件 | 核法 |
|---|---|---|
| T1 连续两季出区间 | 分歧驱动表里**同一行**，本季和上一份判定单都落在"悲观到乐观"区间之外（比悲观线更差或比乐观线更好） | 对照 Step 0 读的上一份判定单。没有历史 → 写"无法核（首次）" |
| T2 单季切情景 | 分歧驱动表里**过半的行**（按行数算，无数据的行不计分母）本季落区与主导情景**偏两档**；或排第一的那行偏两档 | 只看本季 |
| T3 方向反 | 分歧驱动表里排前三的行，本季落区**全部**偏向与主导情景相反的方向，哪怕只偏一档 | 只看本季。主导情景是基准时，"相反"指三行同向偏离（全偏悲观或全偏乐观） |

判定单里每条扳机都要写"命中 / 未命中 / 无法核"加一句依据。无法核不算命中。

### Step 5 — 出判定

**一级反馈（不触发扳机）：**
列出"建议调整的预测参数"——Step 3 里偏离绝对值最大的 2-3 项，写清：现假设值、实际值、建议改到多少、只影响哪个情景。**这是建议，本 skill 不改 06。**

**二级反馈（触发任一扳机）：**
按固定顺序列重审范围，先查的排前面：

| 顺序 | 模块 | 重审理由（把命中的驱动行对上去） | 停查条件 |
|---|---|---|---|
| 1 | 03 商业模式 | 偏差出在收入结构、客户、定价、成本结构的行 | 商业模式判断能解释偏差 → 停在这里 |
| 2 | 04 战略决策 | 偏差出在标了 `[战略→H2/H3]` 的行，或资本配置的行 | 战略判断能解释偏差 → 停在这里 |
| 3 | 01 企业文化 | 前两级都解释不了；或偏差是"说的和做的不一样"（承诺兑现、资本纪律） | 文化判断也要改 → 等于档案重建，提示走 company-dossier-build 全量 |

分配规则：每一行命中的驱动，按它的来源归到 03/04/01 中的一个。06 里标了 `[战略→…]` 的行归 04；没标的、涉及收入/成本/客户的归 03；涉及管理层承诺、资本纪律、组织的归 01。归不进去的单列"来源不明"。

二级判定单末尾写一句：**"是否重审、走哪条路，由用户决定。本 skill 不派刷新。"**

### Step 6 — 写判定单

路径：`{公司目录}/研究档案/_deviation/{YYYY-MM-DD}_{财报期}.md`，例如 `2026-08-22_FY26Q2.md`。目录不存在则创建。

结构（固定，方便下次读）：

```
# {TICKER} 预测偏差分诊 · {财报期}

## 0. 一句话结论
{一级/二级}。{最关键的一条偏差}。{主导情景 + 置信度是否需要重判}。

## 1. 基本信息
- 预测版本：06 source_period = …；主导情景 = …（置信 …，主锚 …）
- 本次新增期数：…
- 历史判定单：… / 无

## 2. 分歧驱动表对照
（Step 2 表）

## 3. 关键假设对照
（Step 3 表）

## 4. 扳机核对
| 扳机 | 结果 | 依据 |
（三行）

## 5. 判定
（Step 5：一级→参数建议表；二级→重审范围表 + 末尾声明）

## 6. 对主导情景的提示
本次计分：{命中/总行数}，与 07 判定一致/不一致。是否建议按估值 skill 的计分制重判：是/否 + 一句理由。

## 附录
- 数据来源：EDGAR financials.json，fetched_at = …
- 未命中指标：（脚本原话）
- 口径说明：每行用的口径（同比/TTM/季节性拆分/事件判据）
- 季节性比例：指标 × 各季占比 × 样本年份；标失效的行写原因
- 指引对照：管理层指引 vs 06 基准假设（如有）
```

写完用 Read 校验文件存在且非空，再向用户汇报。汇报只说三件事：级别、最大偏差、建议下一步。不复述表格。

## 写作要求

- 全程中文。一句话不超过 40 字。缩写第一次出现给人话解释，如"TTM（最近四个季度加总）"。
- 不用"槽/slot""DAG""张力"。数字对不上叫"勾稽不匹配"，判断级冲突才叫"矛盾"。
- 不输出"概率加权"任何形式的综合值。偏差只对主导情景和三条情景线分别算，不做加权平均。
- 表里没有数据就写"无数据"并说明原因，不留空、不估。

## 预算

工具调用 ≤ 20 次。超预算说明原因后停，不硬跑。

## 已知边界

- 分部收入、附注项目不在 XBRL 主表，分歧驱动表里这类行本 skill 核不了，会标"无数据（附注项）"。要核就得读原文，不归本 skill。
- 金融股、本币申报的外币 ADR：脚本不适用，本 skill 直接停。
- 首次跑没有历史判定单，T1 永远无法核。连跑两季后 T1 才生效。
- 06 没有分歧驱动表（旧格式）不分诊，先重跑预测。
