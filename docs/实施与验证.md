## 真实试跑做了什么

实质研究试跑位于 `runs/workflow-trial/Projects`。测试对象为完全虚构的 TESTWAVE，材料、经营指标、价格和所有投资结论都显著标为测试，未混入正式库。这次验证的是研究工作流，不能当作真实公司研究能力或策略盈利能力的实证。

Codex 对登记材料实际完成七模块、三情景五年三表及估值分析。首次技术校验通过后，模拟审阅明确指出“基准收入增长过于乐观”，要求对照订单和续约。系统保存初稿并重写受影响的预测与估值：12个月主价从22.04降至20.68美元，三年基准从28.456383降至24.828515美元。此结果证明格式校验不能替代实质审阅，也证明修订不是仅换一个状态标签。

随后登记单季经营事件，按原事件技能分诊为L1，仅更新06/07并重新接受。主导情景从基准转为悲观，12个月主价降至7.48美元；三年登记仍按原规则使用基准情景，降至20.506504美元。两者期限及情景明确不同。两轮接受、前后来源、计算、差异、总结与事件状态见 [workflow-trial.md](workflow-trial.md) 和该测试目录。

另外依原扫描方法生成过一次合成材料的手动简报，并通过原内容校验；它明确保留行情缺失和单一虚构来源的降级说明，不等同于真实新闻检索。

单独的模拟盘试验使用第一轮已接受研究与合成价格。引擎产生一笔虚拟买入；同日重跑账本不变；11天旧行情触发的退出交易被拦截。没有接券商，也没有把假价格用于正式网页。结果记录在 `runs/paper-trial/result.json`。

## 明确的剩余边界

1. 原战略方法强制引用的 `research-protocol.md`、`decision-framework.md`、`output-template.md` 在固定提交完整目录中不存在。目前只能据现存正文和H1–H5执行并披露缺口，不能声称完全恢复。另 reverse-dcf 的 methodology 参考文件末尾存在截断字符，原字节已按仓库指纹保存，可读副本明确标缺损，没有补写原意。
2. SEC 自动取数需要本用户自己的联系标识 `SEC_USER_AGENT`；尚未提供，因此未验证SEC实际下载。电话会、港股报告、各市场全部备源、外币ADR及金融行业偏差算法也没有全部实测。下载成功不自动证明会计口径适用。
3. AI 每日新闻扫描由用户在 Codex 发起。当前安装的是本机数据维护任务，没有常驻AI执行器；不把自动维护日志当成已做新闻研究或已接受新结论。未执行的简报保持空白。
4. 原模拟盘汇率是配置常数，初始化时须核对。虚拟滑点、整手、候选门槛与仓位规则保留原方法，但不保证真实成交或收益。正式库没有初始化资金与持仓。
5. 上游 `market_rotation_mvp` 是独立周线资金压力工具，此次只查阅边界，未迁入独立界面及同僚样本池。上游“投资研究系统设计”的早期提案明确标为未核验，不能代替当前实现的规范。
6. 新聊天读取项目Skills与磁盘状态的路径已经准备；实际验证了新进程及网页服务重启。未代替用户开启一个全新聊天或重启整台电脑，因此不把这些动作列为已经实测。

本地路径移动、系统退出登录、断网或睡眠会影响定时任务。依赖锁文件在 `config/requirements-market.lock.txt`；虚拟环境不放入备份，恢复到另一环境时按锁文件重建。2026-10-24 的验证仅覆盖本机压缩备份。
