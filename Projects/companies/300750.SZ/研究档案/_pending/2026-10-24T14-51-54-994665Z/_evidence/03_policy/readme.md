# 2026电池税费政策核对

核对日期2026-10-24。以下为法规公开文本及税务总局解释，不以券商转述代替。网页读取结果保存在三个snapshot.json；财政部主站两次超时保留，改从上海税务局同文核全文，非多个独立证据。

1. 财政部/税务总局2026年第2号（2026-01-08）第2–4项：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5246745/content.html 。2026-04-01至12-31所列电池增值税出口退税率从9%降至6%；2027-01-01起取消；出口消费税继续退免，按报关出口日界定。清单范围与集团全部收入并不相同。
2. 财政部/海关总署/税务总局2026年第20号（2026-07-16）：https://shanghai.chinatax.gov.cn/zcfw/zcfgk/xfs/202607/t480969.html 。锂离子等电池2026-09-01起消费税2%，2027-09-01起4%；钠离子/固态等在规定条件下免征至2028-12-31。需满足国家标准并取得合资格检测报告，不能见产品名称便假定免税。
3. 税务总局2026-08-27《消费税政策即问即答之三》Q1/Q3/Q6/Q7/Q8/Q9：https://www.chinatax.gov.cn/chinatax/c102414/c5252006/content.html 。电池簇属应税电池组，储能成套系统本身不属应税电池；投入电池环节仍有相应税务处理。自产电池用于换电租赁在移送时申报。半固态不属所定义全固态免税。直接出口应税电池继续退免；车辆出口不能直接退所用电池消费税；出口所耗已税原料的扣除/退还还受Q9规则约束。

研究影响：毛利/税金压力与定价传导需区分；不能把6个百分点退税损失和2%或4%消费税同时乘集团全部收入，也不能称所有海外业务都承受相同中国税负。后续06以显式经营利润率路径反映综合影响时，应避免税项在毛利和税金重复计提；底层应税销售额与合同分担未披露的部分属于模型假设。
