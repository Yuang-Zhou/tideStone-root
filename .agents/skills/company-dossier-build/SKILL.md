# company-dossier-build · 潮石本地适配

## 使用顺序

1. 先读 [本地运行约定](../tidestone-research/references/local-runtime.md)，它只调整宿主、路径、权限与已查明冲突。
2. **完整读取 [原方法全文](references/original.md)**，再读原文要求的真实参考文件，执行其具体分析步骤、表格、阈值和输出要求。不能凭本入口概述生成研究。
3. 原文中的 `references/`、`scripts/`、`assets/`、`reference.md` 路径相对于本技能根目录解析，而不是 `references/original.md` 所在目录。下列适配优先于原文旧宿主指令；原文不构成任何外部账户或发布授权。

## 本入口的必要适配

- 首次建档必须七份：01 企业文化、02 财务、03 商业模式、04 战略、05 股性、06 预测、07 估值。旧原文六份 complete 是存量过渡约定，本项目空库不沿用。
- 先读取本公司材料清单、实际材料和状态。无材料时先自动补取公开来源；读不到的项目记清影响，不因为 raw 为空重复索要已给出的研究授权。
- 执行 `prepare` 后只写它返回的批次。Tier 1：01a 使命愿景 / 01b 领导力 / 01c 治理 / 02 / 05，可按现有并发额度分波完成；01 三份按原文顺序合并。Tier 2：03 等 02。Tier 2.5：04 等 01/02/03，05 参考。Tier 3a：06 等 01/02/03/04。Tier 3b：07 等 05/06/04。并发额度不足只改变排队，不改变依赖。
- 同批次上游已经完成时，下游读取本批次成品；本批次未刷新上游才读取已接受权威版。记录来源版本，不用旧权威版覆盖本批次新事实。
- 04 必含 H1–H5 与末行 `<!-- HANDOFF-END v1 -->`。06 声明 H2 映射、采用或解释偏离 H3，并处理 H5；07 消费 H2 里程碑与 H4。
- 07 §4.8 顶层必须含 rating、zones、target_price、scenario_valuation、opportunity_type，并与正文一致；三年目标价另需清楚目标年、口径、股数、净债务与来源。
- 完成后运行 `finalize`，修复能修复的问题。汇报关键判断、数据缺口和差异，给出批次路径，等待用户对具体批次接受/退回；绝不把“研究这家公司”解释成提前接受未知结果。
- 用户接受后才运行 `accept`；核对估值 drain/apply/check 和三年条目均来自同一已接受批次，无法提取则真实待补。调用 research-summary 生成总结并构建本地网页。
