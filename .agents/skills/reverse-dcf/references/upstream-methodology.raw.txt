# 反推DCF方法论参考手册

## 核心逻辑

正向DCF：给定假设 → 算出公司价值  
反推DCF：给定市场价格 → 反推市场隐含的增长预期

等式两端互换：左边（EV）已知，右边（CAGR）是未知数。

---

## 第一步：计算企业价值 EV

```
EV = 市值 + 有息负债 - 现金及等价物
   = Market Cap + Interest-bearing debt - Cash & equivalents
```

- 若净现金（现金 > 有息负债），EV < 市值
- 市值用当日真实市价，不能用旧数据
- 跨币种统一换算（如 JPY/USD 150，EUR/USD 1.08）

---

## 第二步：计算基年 FCFF（最关键步骤）

**推荐方法A（现金流量表法）**

```
FCFF ≈ CFO（经营活动现金流）- Capex + 税后利息支出
```

CFO 是审计过的真金白银，优先用此法。

**方法B（NOPAT bottom-up，做交叉验证）**

```
FCFF = NOPAT + D&A - Capex - ΔWC
NOPAT = 营业利润 × (1 - 有效税率)
```

**取两种方法均值作为基年 FCFF。**

### 关键细节

| 项目 | 正确做法 | 常见错误 |
|------|----------|----------|
| 税率 | 用实际有效税率（财报倒算）| 套用法定税率（如中国25%、韩国24%） |
| D&A | 从财报附注或现金流量表取 | 拍脑袋估算 |
| Capex | 从现金流量表投资活动项取 | 混入研发费用 |
| ΔWC | CFO与NOPAT差额反推 | 忽略不计 |

### 基年选择是判断题

| 情景 | 推荐基年 | 含义 |
|------|----------|------|
| 公司处于周期顶部 | 3-5年平均FCF | 更保守；反推CAGR会更高 |
| 公司处于周期底部或盈利刚起步 | 当期run rate年化 | 贴近未来预期 |
| 稳定成熟公司 | 最新FY数据 | 最直接 |

## 第三步：计算 WACC

```
WACC = Re × We + Rd × (1-t) × Wd

Re = Rf + β × ERP
```

```
β_levered = β_unlevered × [1 + (1-t) × D/E]
```

## 第四步：两阶段DCF框架反推

### 模型结构

- 显性期：10年（CAGR为待求未知数）
- 终值：Exit Multiple法（**推荐**）

### 终值：Exit Multiple法（推荐）

```
TV = 第10年 FCFF × 退出倍数
```

**推荐退出倍数场景：**

| 场景 | 退出倍数 | 适用 |
|------|----------|------|
| 保守 | 10x | 强周期股、传统行业 |
| 基准（推荐） | 15x | 成熟科技股 |
| 乐观 | 20x | 高成长科技股 |
| 激进 | 25x | 垄断性平台公司 |

Gordon Growth法说明（备选）：

```
TV = FCF₁₀ × (1+g) / (WACC - g)    g通常取2.5%
```

注意：GG法暗含"10年后以约10x倍数退出"，对科技股系统性高估CAGR约3-7pt。

### 反推公式

EV = Σ[FCFFₜ / (1+WACC)ᵗ] + TV / (1+WACC)¹⁰

其中 FCFFₜ = FCFF₀ × (1+CAGR)ᵗ

**求解CAGR使等式成立**（用二分法或Goal Seek求解）。

## 第五步：敏感性分析表

构建二维敏感性表，横轴退出倍数，纵轴CAGR：

| CAGR ↓ / 退出倍数 → | 10x | 15x | 20x | 25x |
|---------------------|-----|-----|-----|-----|
| 15% | EV₁ | EV₂ | EV₃ | EV₄ |
| 20% | ... | ... | ... | ... |
| 25% | ... | ... | ... | ... |
| 30% | ... | ... | ... | ... |

标出最接近实际EV的格子，该行CAGR = **市场隐含增长预期**。

---

## 结果解读框架

得到隐含CAGR后，做三个翻译：

### 翻译1：10年后公司规模

```
10年后FCFF = 基年FCFF × (1+CAGR)¹⁰
10年后收入 ≈ 10年后FCFF / FCF转化率（近似用当前值）
```

### 翻译2：与行业历史比较

| 参照 | 10年收入CAGR |
|------|-------------|
| Amazon 2005-2015 | 28.8% |
| Meta 2012-2022 | 37.1% |
| Tesla 2014-2024 | 40.7% |
| NVIDIA 2015-2025 | 38.5% |
| 台积电过去20年 | ~18% |
| SK海力士过去10年 | ~13% |

### 翻译3：与管理层guidance比较

如果管理层给出了收入/利润增长指引：

```
gap = 隐含CAGR - 管理层指引中点
```

- gap > 10pt：市场显著比管理层更乐观，存在"长期叙事溢价"
- gap 5-10pt：市场有一定溢价，需关注兑现节奏
- gap < 5pt：市场与管理层基本对齐

---

## 常见陷阱

| 陷阱 | 后果 | 预防 |
|------|------|------|
| 用法定税率算NOPAT | FCFF被低估 → 隐含CAGR虚高 | 用财报实际税率（税前利润vs所得税费用倒算） |
| 用GG法替代Exit Multiple | 对科技股CAGR系统高估3-7pt | 优先Exit 15x，GG作辅助 |
| 基年选周期顶部 | CAGR看起来保守，实为高�
