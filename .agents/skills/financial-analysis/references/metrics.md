# 各项指标怎么算（全库统一，不同公司必须用同一套）

## 利润与回报

- **NOPAT** = 营业利润 × (1 − 标准化税率)。标准化税率 = 近 3 年有效税率中位数，截断在 [10%, 35%]；有效税率为负或异常年份剔除。
- **投入资本（经营法）** = 经营性营运资金 + 固定资产净值 + 使用权资产 + 无形资产 + 商誉。同时给 **不含商誉** 版本。
- **ROIC** = NOPAT / 期初期末平均投入资本。两版都报：含商誉（算上收购花的钱，真实回报）、不含商誉（生意本身的回报）。
- **ROE 拆解** = 净利率 × 总资产周转 × 权益乘数。三项各看五年方向，判断 ROE 是靠赚钱、靠周转快，还是靠借钱。
- **增量利润率** = (营业利润₍t₎ − 营业利润₍t-3₎) / (收入₍t₎ − 收入₍t-3₎)。分母 ≤0 时不算，写 n/a。
- **再投资率** = (资本开支 − 折旧摊销 + Δ经营性营运资金 + 并购现金支出) / NOPAT。
- **资本开支产出** = 3 年累计 Δ收入 / 同期累计资本开支。

## 营运资金与周转

- **经营性营运资金** = (应收 + 存货 + 预付) − (应付 + 应计费用 + 递延收入/合同负债)。**不含现金、不含有息负债。**
- **存货天数** = 平均存货 / 营业成本 × 365；**应收天数** = 平均应收 / 收入 × 365；**应付天数** = 平均应付 / 营业成本 × 365。
- **现金转换周期** = 存货天数 + 应收天数 − 应付天数。
- **营运资金/收入**（F2 用）= 期末经营性营运资金 / 当年收入。

## 现金流

- **自由现金流** = 经营现金流 − 资本开支。不减并购、不减租赁本金；租赁本金单独列。
- **扣股权激励后的自由现金流** = 自由现金流 − SBC。F2 两版都给。
- **经营现金流/净利润**：分子分母同口径（净利润含少数股东则经营现金流也含）。

## 资本配置台账

- 六项 + 股权激励：资本开支、研发（费用化 + 资本化）、并购（现金净支出）、回购（现金支出）、分红、**净还债**（还的减新借的；负数表示净借入）、股权激励（SBC）。
- 分母 = 同期经营现金流累计。股权激励一行标"非现金"。

## TTM 处理

- **直接用底稿 `ttm.flow` / `ttm.instant`，不自己算。** 脚本的算法是：财年值 + 本财年累计 − 去年同期累计；缺去年同期的指标为 null，填 n/a。
- A股港股底稿没有 TTM 时：写"TTM 不可得"，用最近财年代替并标注。
- 比率：流量/流量用 TTM；流量/存量用 TTM 流量 ÷ 最近期末存量。需要期初期末平均存量的指标（ROIC、周转天数、增量利润率）TTM 列填 n/a。
- **TTM 不参与"方向"判断**，方向只看财年列。

## 增速与均值

- 收入增速逐年 = 本年/上年 − 1；F2 的"5 年"栏用 **CAGR**，不用算术平均。
- 比率类的"5 年"栏用算术平均，用剔除一次性项目后的数。
- 有并购并表的年份，增速旁标 `†`，表下注明不含并购的增速（能拆的话）。

## 偿债与流动性（第 1 步财务安全体检用）

- **有息负债（含租赁）** = 短期借款 + 长期借款 + 经营租赁负债（流动 + 非流动）+ 融资租赁负债（流动 + 非流动）。F3 基年"有息负债（含租赁）"同此口径。
- **净负债** = 有息负债 − 现金及等价物 − 短期投资。负数写"净现金 X"。
- **EBITDA** = 营业利润 + 折旧摊销。不加回 SBC、不加回一次性项目；要给剔一次性后的版本时另标。
- **净负债/EBITDA**：净负债为负时填"净现金"，不算负倍数。EBITDA ≤0 时填 n/a。
- **利息覆盖** = 营业利润 / 利息支出；**现金利息覆盖** = 经营现金流 / 利息支出。利息支出为 0 或未披露填 n/a，不写"无穷大"。
- **FCF/有息负债** = 自由现金流 / 期末有息负债。理解为"几年还清"的倒数。
- **现金/1 年内到期债务** = (现金及等价物 + 短期投资) / (短期借款 + 一年内到期长期借款 + 租赁负债流动部分)。
- **流动比率** = 流动资产 / 流动负债；**速动比率** = (流动资产 − 存货) / 流动负债。底稿缺流动资产/负债合计时去附注取，取不到填 n/a。
- **3 年内到期占比** = 附注到期表中 3 年内到期本金 / 有息负债本金（不含租赁）。
- **浮动利率占比**、**加权平均利率**：附注原文，没有就 n/a。

## 资产质量（第 1 步财务安全体检用）

- **商誉无形占比** = (商誉 + 无形资产) / 总资产。
- **有形权益** = 股东权益 − 商誉 − 无形资产。为负照实写。
- **减值测试余量（headroom）**：附注原文"公允价值超过账面价值 X%"，按报告单元列最小值。
- **应收增速差** = 应收账款增速 − 收入增速（百分点）。
- **坏账计提率** = 坏账准备 / 应收账款总额（附注）。
- **存货增速差** = 存货增速 − 收入增速（百分点）。
- **跌价计提率** = 存货跌价准备 / 存货总额（附注）。
- **资本化比例** = 资本化研发或开发支出 / (费用化研发 + 资本化支出)。
- **折旧率** = 当年折旧 / 固定资产原值（附注取原值；取不到用净值并标注）。5 年下降 >2 个百分点且资本开支没降，查会计估计变更。
- **递延税资产/总资产**。

## 旗的判定（提示，不是判决）

| 指标 | 黄旗 | 红旗 |
| :-- | :-- | :-- |
| 净负债/EBITDA | >3 | >4，或到期集中且 FCF 覆盖不了 |
| 利息覆盖 | <3 且下降 | <1.5 |
| 现金/1 年内到期债务 | <1 | <0.5 且经营现金流为负或大幅波动 |
| 3 年内到期占比 | >50% | >50% 且 FCF/有息负债 <10% |
| 商誉无形占比 | >40% | headroom <10% |
| 应收增速差 | >10pt 连续两年 | 同时坏账计提率下降 |
| 存货增速差 | >10pt 且产成品占比升 | 同时跌价计提率下降 |
| 资本化比例 | 5 年上升 >5pt | 同时研发费用率下降 |

重资产、公用事业、金融、REIT 的阈值另行参照行业惯例，正文写明用的是哪个参照。

## 金融公司（银行 / 保险 / 券商）替代指标

毛利率、资本开支、营运资金、现金转换周期对金融公司没意义，F2 对应行填 `n/a`，换成下面这些：

| 类型 | 替代行 |
| :-- | :-- |
| 银行 | 净息差、成本收入比、不良率、拨备覆盖率、核心一级资本充足率、贷款增速、非息收入占比 |
| 保险 | 综合成本率（财险）/ 新业务价值增速（寿险）、投资收益率、偿付能力充足率、准备金/保费 |
| 券商 / 资管 | 管理资产规模及增速、费率、经纪/自营/投行收入结构、杠杆倍数 |

REIT：用 FFO、AFFO、出租率、同店租金增速、净负债/EBITDA 替代营业利润率和营运资金行。
