# daily-position-advisor · 潮石本地适配

## 使用顺序

1. 先读 [本地运行约定](../tidestone-research/references/local-runtime.md)，它只调整宿主、路径、权限与已查明冲突。
2. **完整读取 [原方法全文](references/original.md)**，再读原文要求的真实参考文件，执行其具体分析步骤、表格、阈值和输出要求。不能凭本入口概述生成研究。
3. 原文中的 `references/`、`scripts/`、`assets/`、`reference.md` 路径相对于本技能根目录解析，而不是 `references/original.md` 所在目录。下列适配优先于原文旧宿主指令；原文不构成任何外部账户或发布授权。

## 本入口的必要适配

- 本地移植不继承同僚 IBKR 账户、历史仓位、个人胜率、教训或真实交易权限。原文例子仅为格式说明，绝不可写成本用户事实。
- 使用用户已提供的本地快照，或另行明确授权并实际连接的只读账户；没有数据则报告未接入，不生成“零持仓/无告警”。
- 若 position_triggers.json 未由本用户建立，不能使用同僚规则硬编码生成纪律建议。取完整性通过的引擎 verdict 并翻译，错误需查明，不用语言估算替代引擎。
- 报告和本地网页更新可执行；外部 Artifact、账户交易和发送通知均不继承原文权限。
